# matrix — библиотека матричных операций на C
Учебный проект, School 21
Стек: C11, GCC, Make, Check, gcov, Git, Linux

Разработал статическую библиотеку s21_matrix.a из 11 функций: создание/удаление, сравнение, сложение, вычитание, умножение на число и матрицу, транспонирование, определитель, алгебраические дополнения, обратная матрица.

Реализовал динамическое управление памятью, обработку ошибок через коды возврата и точность вычислений до 6 знаков после запятой.

Покрыл каждую функцию unit-тестами на Check (покрытие >80%), настроил генерацию HTML-отчёта gcov через Makefile.

Соблюдал Google Style, POSIX.1-2017 и принципы структурного программирования. Проект сдан на 100%.
